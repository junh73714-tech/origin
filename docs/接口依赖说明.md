# 成员2 接口依赖说明（前端视角）

本文件记录成员2前端所消费的接口契约（前端视角的字段约定），供联调时与成员4/6/7、成员1 逐条核对。
最终以成员1维护的 `docs/api-contracts.md` 为准；如有出入以契约为准，前端不得私自改字段。

## 统一约定

- 成功响应：`{ code, message, data, request_id, trace_id }`，`code` 为 "0"/"SUCCESS" 表示成功；
- 鉴权：请求头 `Authorization: Bearer <access_token>`，`X-Request-Id` 由前端生成；
- 错误码（前端分支用）：见 `src/types/common.ts` 的 `ErrorCode`。

## 成员4：认证与权限

| 用途 | 方法 | 路径 | 请求 | 响应 data |
|---|---|---|---|---|
| 登录 | POST | /auth/login | LoginRequest | TokenPair |
| 刷新 | POST | /auth/refresh | { refresh_token } | TokenPair |
| 退出 | POST | /auth/logout | — | — |
| 当前用户 | GET | /auth/me | — | CurrentUser |
| 权限摘要 | GET | /auth/permissions | — | PermissionSummary |
| 密码重置 | POST | /auth/reset-password | PasswordResetRequest | — |

后端关联模型：Department / UserGroup / DataScope / TemporaryGrant / LoginLog / KnowledgeBasePermission / DocumentPermission。
登录相关环境变量（AUTH_LOGIN_MAX_ATTEMPTS / AUTH_LOGIN_LOCKOUT_MINUTES）由成员4后端控制；
前端在锁定时会收到 `AUTH_LOGIN_LOCKED` 错误码并提示剩余锁定时长。

类型见 `src/types/auth.ts`。

## 成员6：会话、SSE、引用

| 用途 | 方法 | 路径 | 响应 data |
|---|---|---|---|
| 会话列表 | GET | /conversations?page&page_size&keyword | PageResult<Conversation> |
| 新建会话 | POST | /conversations | Conversation |
| 会话详情 | GET | /conversations/:id | ConversationDetail |
| 重命名/归档 | PATCH | /conversations/:id | — |
| 删除 | DELETE | /conversations/:id | — |
| 停止生成 | POST | /conversations/:id/messages/:mid/stop | — |
| 流式问答 | POST | /chat/ask/stream | text/event-stream |
| 引用详情 | GET | /citations/:citation_id | CitationDetail |

SSE 事件序列：`message_start` → `answer_delta`(多次) → `citation`(多次) → `metadata` → `done`；异常时 `error`。
前端以 `done` 事件的完整结果为最终值。类型见 `src/types/chat/index.ts`。
