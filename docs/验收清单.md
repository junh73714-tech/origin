| 验收项 | 状态 | 实现位置 |
|---|---|---|
| 登录（校验、防重复提交、失败/禁用/过期提示、退出） | 通过 | pages/user/LoginPage、components/user/auth/LoginForm、stores/authStore |
| Refresh Token 协作、认证失效统一跳登录页 | 通过 | api/http.ts（拦截器静默刷新）、authStore.forceLogout |

| 流式答案、停止生成、重新生成、处理中状态 | 通过 | stores/chat/chatStore、components/user/chat/* |
| answer_type 展示（标准问答/RAG/参考/拒答） | 通过 | components/user/chat/AnswerStatus、AssistantMessage |
| 引用编号、可信度/证据状态、拒答原因 | 通过 | AnswerStatus、RefusalNotice、CitationBadge |

| 历史会话（列表/搜索/重命名/删除/归档/选中态/空状态，删除归档二次确认） | 通过 | pages/user/HistoryPage、components/user/conversation/* |

## 二、安全与权限（任务书 §8、§11）

| 验收项 | 状态 | 说明 |
|---|---|---|
| 前端不重实现权限/RAG 判断 | 通过 | 仅消费后端返回结果 |
| 无权限引用不泄露真实地址与正文 | 通过 | CitationDrawer 依据 access_denied / can_open_source 分支 |
| 不展示 Chunk ID、DB ID、存储路径，不拼接 MinIO 地址 | 通过 | 类型层不含内部标识，仅用 citation_id |
| 切换用户后无跨账号缓存 | 通过 | resetBus 统一重置全部 Store；Token 不入 LocalStorage |
| Markdown 防 XSS，外链安全属性 | 通过 | utils/markdown.ts（DOMPurify + afterSanitizeAttributes） |
| 不在日志输出 Token、不展示后端堆栈 | 通过 | http 拦截器仅透出可理解 message |
| 登出清理 SSE 连接 | 通过 | chatStore reset 内 controller.abort() |

## 四、测试覆盖明细

单元/组件（Vitest，tests/user/）：
- LoginForm：必填校验、提交回调、错误提示（3）
- authStore：登录成功、禁用账号、错误密码、登出清缓存（4）
- chatStore：增量合并+done为准+引用、拒答无正文、停止生成（3）
- conversationStore：加载、重命名、删除、归档（4）
- 拒答与 Markdown 安全渲染：拒答提示、剔除 script、外链安全属性（3）
- CitationDrawer：有权限展示原文、无权限不泄露（2）

端到端（Playwright，tests/e2e/user-chat.spec.ts）：
- 登录进问答页 / 发送问题收流式答案并打开引用 / 拒答提示 / 查看历史会话 / 无知识库权限提示 / 禁用账号被拒（6）
