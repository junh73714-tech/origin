# 已知问题与技术债务

## 已知问题

1. **页面刷新需重新登录**
   出于安全考虑，Token 仅保存在内存、不持久化到 LocalStorage，故刷新页面后需重新登录。
   正式环境如需“记住登录”，应由成员1/成员4 提供基于 HttpOnly Cookie 的方案，前端不自行持久化敏感令牌。

2. **构建产物单包体积偏大（约 1.1MB，gzip 约 364KB）**
   AntD 全量引入所致。集成到成员1统一工程后，建议统一做路由级懒加载与 `manualChunks` 拆包，本独立工程未做拆包以保持结构简单。

3. **Playwright 端到端依赖本地 dev server**
   `npm run test:e2e` 会自动拉起 dev server；首次运行需 `npx playwright install chromium` 安装浏览器内核。CI 中由成员1统一配置。

## 技术债务

1. **Mock 与真实契约的一致性需在联调期复核**
   当前 Mock 严格按任务书 §7 接口清单与字段设计。正式联调前须与成员4/6/7 对照 `docs/api-contracts.md` 逐字段确认，尤其是 SSE 事件名、错误码枚举与分页格式。

2. **公共基础设施为本工程内的等价实现**
   `src/api/http.ts`、`src/theme.ts`、`src/routes.tsx` 在正式项目中应替换为成员1维护的共享版本。合并时删除本地副本，改为引用共享模块，避免与成员3重复建设。

3. **推荐问题、系统公告等首页模块**
   推荐问题已接入成员7接口（Mock）；系统公告、常用问题当前为占位，待成员7/成员1 提供对应接口后补齐，不硬编码企业事实。

4. **SSE 断线重连策略**
   当前实现为断线后提示“重新生成”，未做自动重连与断点续传。若后端支持续传，可在 sseClient 增加 `Last-Event-ID` 协作。
